# 의도분석 최적화 

## 워크플로우 
- 새로운 브랜치로 분기
- 완벽한 에이전트 동작을 위해 필요하다가 판단되는 툴이 있다면 **가상의 카달로그에 툴 추가**
- 에이전트 스러운 동작을 하기위한 복잡한 **케이스를 최소 100개 이상 추가** (기존에 PASS 되었던 문항도 그대로 포함한다. )
- **P2(오라클 검증)**을 직접 수행후 보정 ( 보정이 완료될 때까지 반복. )
- P2(오라클 검증)가 완료되면 **P3 진행**(진행 파라미터는 아래 기준 섹션 참조 프롬프트 왜 노드 수정 가능. )
- 모든 작업이 종료되면 최종 보고서 작성 ( 아래 리포트 섹션 참조. )

## 기준 
| 상수 | 기본 | 의미 |
|------|------|------|
| `GOLDEN_TARGET` / `HOLDOUT_TARGET` | 0.90 / 0.90 | 성공(정지) 통과율 |
| `HOLDOUT_FLOOR` | 0.85 | 이 밑으로 떨어지면 과적합으로 보고 채택 거부 |
| `MAX_ROUNDS` | 12 | 라운드 상한 |
| `K_NOPROGRESS` | 3 | 연속 무진전 정지 횟수 |
| `REPS_ITER` / `REPS_FINAL` | 3 / 5 | 반복 중 / 확정 시 채점 반복 횟수 |
